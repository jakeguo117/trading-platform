## 阅读规则

每项研究都按四件事记录：

1. 研究问题；
2. 实际观察或结论；
3. 成熟度；
4. 限制与源文件。

常见状态：

- `COMPLETED_OBSERVATION`：研究或资料审查已经完成，不代表策略通过。
- `SYNTHETIC_ONLY`：只证明机械流程。
- `NOT_BLIND_VALIDATED`：未完成独立盲测。
- `INSUFFICIENT_EVIDENCE`：合法结论是证据不足。
- `NOT_RUN_NOT_AUTHORIZED`：只有设计或预注册，没有获准运行。
- `TERMINATED`：该条研究路线已经停止，不代表相关结构在所有条件下都无效。
